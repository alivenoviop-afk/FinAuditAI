# Архитектура FinAuditAI

## Цель

Платформа, где компания может:
1. **Выбрать модель** — локальную (Ollama/HuggingFace) или API (OpenAI, Claude, OpenAI-совместимые);
2. **Тренировать её** — fine-tuning (LoRA) на размеченных аудит-кейсах;
3. **Прогонять файлы** — загрузить бухгалтерские документы и получить структурированный аудит-вывод;
4. **Проверить качество** — прогон через FinRepGYM (P/R/F1, награда).

┌──────────────────────────▼─────────────────────────────────┐
│                    FastAPI (backend)                        │
│  api/models  api/training  api/inference  api/files  api/eval│
└──────┬───────────────┬───────────────┬─────────────┬───────┘
       │               │               │             │
┌──────▼──────┐ ┌──────▼──────┐ ┌──────▼──────┐ ┌────▼────────┐
│  Model      │ │  Trainer    │ │  Pipeline   │ │  Evaluator  │
│  Registry   │ │  (LoRA/PEFT)│ │  parse→chunk│ │  FinRepGYM  │
└──────┬──────┘ └──────┬──────┘ └──────┬──────┘ └────┬────────┘
       │               │ (фоново)      │             │
┌──────▼───────────────▼───────────────▼─────────────▼───────┐

## Ключевые компоненты

### 1. Провайдеры моделей (`backend/app/providers/`)

Единый абстрактный интерфейс `ModelProvider`:
- `list_models()` — список доступных моделей;
- `run(model_id, messages)` — инференс;
- `can_train(model_id)` / `train(...)` — обучение (только локальные);
- `health()` — проверка доступности.

Реализации:
- `local.py` — **Ollama** (HTTP API, `http://localhost:11434`) и **HuggingFace** (LoRA/PEFT через transformers);
- `api.py` — любой **OpenAI-совместимый** эндпоинт (OpenAI, Claude через совместимый мост, внутренние LLM компании) + нативный Anthropic.

Добавление нового провайдера = один новый файл + регистрация в `registry`.

### 2. Реестр моделей (`core/model_registry.py`)

Таблица `models` в БД: имя, тип (`local`/`api`), провайдер, endpoint, ключ (шифруется/в env),
флаг `can_train`, статус. UI читает единый список с фильтром «локальные / API».

### 3. Тренировка (`core/trainer.py`)

- Датасет: JSONL в `data/datasets/` (`{"input": ..., "output": ...}`) — формат совместим с экспортом траекторий FinRepGYM;
- Алгоритм: **LoRA (PEFT)** — дёшево, сохраняет базовую модель;
- Задачи выполняются фоново (ThreadPool/Celery+Redis), статус и логи — в БД, отдаются в UI;
- Результат: чекпоинт в `data/models/`, регистрация в реестре как новая доступная модель.

### 4. Пайплайн прогона файлов (`core/pipeline.py`)

```
файл (PDF/XLSX/CSV/JSONL/DOCX)
  → парсинг (pdfplumber, openpyxl, csv, python-docx)
  → чанкинг по ~4000 символов с перекрытием
  → промпт (роль аудитора + чек-лист + чанки)
  → инференс у выбранной модели
  → нормализованный JSON-вывод {findings: [{type, affected_ids, amount, evidence}]}
  → сохранение отчёта в БД (история)
```

### 5. Проверщик FinRepGYM (`core/evaluator.py`)

- Клонирует/использует [FinRepGYM](https://github.com/alivenoviop-afk/FinRepGYM) в `data/finrepgym/`;
- Оборачивает модель в **политику среды** (действия `list_records`, `get_record`, `get_document`, `calculator`, `submit`);
- Прогоняет эпизоды (`episodes/train`, `episodes/dev`) и собирает метрики: **P, R, F1, reward, шаги, время**;
- Метрики пишутся в таблицу `eval_results` — видны в UI рядом с моделью.

Формат данных совместим: траектории/находки модели сопоставляются с `truth.json` через `matcher.py` FinRepGYM.

### 6. Хранилище (`db/`)

SQLite по умолчанию (легко), PostgreSQL через `DATABASE_URL` (масштаб).
Таблицы: `models`, `training_jobs`, `runs` (прогоны файлов), `eval_results`, `files`.

## Масштабирование

- **Сейчас:** один процесс FastAPI + фоновые задачи, SQLite, локальные файлы.
- **Рост:** PostgreSQL, Redis + Celery для воркеров, S3 для файлов, отдельный GPU-нода для обучения — интерфейсы провайдеров и API не меняются.
- **Мультитенантность:** ключи API и модели привязываются к организации (поле `org_id` готово к добавлению).

## Безопасность

- API-ключи хранятся в `.env` / env-переменных, не в БД;
- Загруженные файлы — только в `data/uploads/`, валидация расширений;
- Нет shell/SQL/сети в среде FinRepGYM для агента (контракт среды).
